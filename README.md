# 🔍 AI Research Agent

An AI-powered research assistant that automates information gathering, analysis, and report generation on user-specified topics.

The application leverages Large Language Models (LLMs) and web-based information retrieval to conduct structured research, summarize findings, and generate comprehensive reports in a user-friendly format.

---

## 🌐 Live Demo

https://research-agent-xcm7chbaqf9rmit4jdvby2.streamlit.app/

---

## 📌 Overview

Conducting research manually often requires gathering information from multiple sources, reading lengthy articles, and organizing findings into a coherent report.

The AI Research Agent simplifies this process by:

- Understanding user research queries
- Collecting relevant information
- Analyzing multiple sources
- Generating structured summaries
- Producing comprehensive research reports

The goal is to reduce research time while improving information accessibility and productivity.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/dishaprabhakar2006-blip/research-agent.git
```

### Navigate to Project Directory

```bash
cd research-agent
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key
```

or

```env
GEMINI_API_KEY=your_api_key
```

## ⚙️ How It Works

1. User enters a research topic.
2. The agent interprets the query.
3. Relevant information is collected from available sources.
4. The AI model analyzes and synthesizes findings.
5. Key insights are extracted.
6. A structured research report is generated.
7. Results are displayed through the Streamlit interface.
